# DrawDO

this is my proejct for hack club stardance!! 
its a todo list but instead of typing u can draw your tasks. i thought typing is boring so drawing is much cooler.

here is the live link to try it: https://evinjsubin.github.io/DrawDo/

### how it works
i used html canvas to make the drawing part work. you can chose colors and how thick the brush is. there is also a secret neon mode if u click the lightning icon it glows!!

### features
- draw tasks on canvas
- neon glow brush
- u can switch to typing if u want
- dark mode (click the moon)
- 3d tilt effect when u hover over cards it looks like its floating
- cool delete anmation

### how to run
just open the link above or download the files and click index.html. it dosent need any servers or npm stuff just pure js and html.
